## What and why

Statement exports can be canceled, and a list says how close the root account
is to its limit.

- `StatementExportService.CancelStatementExport`, REST
  `POST /v1/statements/exports/{exportId}/cancel`, stops a `QUEUED` or
  `PROCESSING` export. It becomes `CANCELED` at once: it no longer counts
  toward the root account's 5 exports in progress, the account's next export
  can start, and any partial file is deleted.
- `StatementExportStatus` gains `STATEMENT_EXPORT_STATUS_CANCELED`.
- `ErrorCode` gains `ERROR_CODE_STATEMENT_EXPORT_NOT_CANCELABLE`, for canceling
  a `READY`, `FAILED` or `EXPIRED` export, and
  `ERROR_CODE_STATEMENT_EXPORT_CANCELED`, for downloading a canceled export.
- `ListStatementExportsResponse` gains `in_progress_exports`, the root
  account's exports `QUEUED` or `PROCESSING` across all its subaccounts, and
  `max_in_progress_exports`, the limit. Both are filled whichever account the
  list selects.

## How clients use it

```http
POST https://<api-host>/v1/statements/exports/{exportId}/cancel
```

```json
{"export": {"exportId": "…", "status": "CANCELED", …}}
```

- ConnectRPC: `POST /ledger.read.v1.StatementExportService/CancelStatementExport`
  with `{"exportId": "<exportId>"}`. Session tokens and API keys with the
  `READ_STATEMENTS` policy action may call it, with the same access as
  `GetStatementExport`.
- Canceling a `CANCELED` export again returns it unchanged. A finished export
  answers `FAILED_PRECONDITION` with `STATEMENT_EXPORT_NOT_CANCELABLE` (REST
  `409`).
- `/file` and `/download-url` of a `CANCELED` export answer
  `STATEMENT_EXPORT_CANCELED` (REST `409`).
- Show the room left with `inProgressExports` and `maxInProgressExports` from
  any `ListStatementExports` response, and disable creating while they are
  equal.

## Migration

None: everything is added. Clients that switch on `StatementExportStatus` or
`ErrorCode` should handle the new values; an older client sees `CANCELED` as
an unknown status.
