## What and why

A new service, `auth.v1.ConnectedAppService`, lets a signed-in account connect
an outside app, such as an AI assistant, with OAuth ("Sign in with Polyester"),
and list and disconnect the apps it connected. The app's own OAuth flow sends
the browser to the website's consent page with a request ID; the page reads the
request (`GetAppAuthorization`) and approves (`ApproveAppAuthorization`) or
denies (`DenyAppAuthorization`) it. `ListConnectedApps` and
`RevokeConnectedApp` back an account settings page.

A connected app reads the account as the signed-in website does, for the scope
`account:read`; it never moves money out of the account and never changes its
security settings. A connection lasts until the account or the app disconnects
it, or until it expires; signing out of the website does not end it.

`auth.v1.AuthErrorCode` gains `AUTH_CONNECTED_APP_LIMIT_REACHED = 73` (an
account already has 20 connected apps).

## How clients use it

Every method needs the website session token; an API key is refused.

```text
POST /auth.v1.ConnectedAppService/GetAppAuthorization
{"requestId": "<from the consent page's request query parameter>"}

POST /auth.v1.ConnectedAppService/ApproveAppAuthorization
X-Auth-Step-Up: <fresh step-up proof from an MFA challenge>
{"requestId": "<request ID>"}
→ {"redirectUrl": "https://app.example/callback?code=...&state=..."}

POST /auth.v1.ConnectedAppService/DenyAppAuthorization
{"requestId": "<request ID>"}
→ {"redirectUrl": "https://app.example/callback?error=access_denied&state=..."}

POST /auth.v1.ConnectedAppService/ListConnectedApps
{}
→ {"apps": [{"connectedAppId": "...", "client": {"clientId": "...", "name": "..."},
             "scopes": ["account:read"], "resource": "...", "connectedAt": "...",
             "lastUsedAt": "...", "expiresAt": "..."}]}

POST /auth.v1.ConnectedAppService/RevokeConnectedApp
{"connectedAppId": "..."}
```

Approving needs enrolled MFA and a fresh step-up proof in `X-Auth-Step-Up`,
as creating an API key does; an MFA-elevated session alone is not enough. After
approving or denying, the client navigates the browser to `redirectUrl`. An
unknown, expired or already answered request is NotFound. `ListConnectedApps`
returns at most 20 apps, newest first, without paging. `RevokeConnectedApp` is
idempotent. None of the methods has a REST route.

## Migration

None: the service and the error code are new.
