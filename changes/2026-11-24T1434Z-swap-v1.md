## What and why

`SwapService` gains `ListSwaps`: it lists the caller's Swaps funded by one
account, the root account or a sub-account, newest first, each as `GetSwap`
returns it. With `open_only` it lists only the Swaps that have not ended
(`is_terminal` false). A client that lost track of a Swap, for example a page
reloaded during a TWAP, finds it again with one read instead of needing the
Swap's ID or idempotency key.

`ListSwaps` takes the same credentials and permission as `GetSwap`: the SWAP
permission on the funding account, through the caller's role or the API
key's policy. A caller lists exactly the Swaps it could read one by one with
`GetSwap`, a sub-account that is not active included, so its open Swaps can
be found and canceled. `subaccount_id` selects the funding account as `SwapTerms` does:
omitted, it is the caller's root account, or the sub-account an API key is
bound to.

## How clients use it

ConnectRPC:

```bash
curl -sS https://<api-host>/swap.v1.SwapService/ListSwaps \
  -H 'Content-Type: application/json' -H 'Authorization: Bearer <session>' \
  -d '{"openOnly": true, "limit": 20}'
```

```json
{"swaps": [{"swapId": "…", "status": "EXECUTING", "isTerminal": false, "…": "…"}], "nextPageToken": "…"}
```

- `limit`: 0 means 20, at most 50; more is `INVALID_ARGUMENT`.
- Order: creation time, newest first, with a stable tie-breaker for Swaps
  created at the same instant.
- Paging: pass `nextPageToken` back as `pageToken` with the same
  `subaccountId` and `openOnly`; it is empty on the last page. A token from
  another listing, or a malformed one, is `INVALID_ARGUMENT`. Each page
  continues strictly after the last Swap of the page before it and holds the
  Swaps as they are when it is read, so a listing never repeats a Swap and
  never skips one that existed when the listing started and still matches the
  filter. A Swap created while a listing is under way is listed on a later
  page only if it sorts after the last Swap already listed; otherwise it
  appears only when listing starts again. With `openOnly`, a Swap that ends
  between pages is left out of the later ones.
- Errors: those of `GetSwap` and of `subaccount_id` in `QuoteSwap`, except
  that a sub-account that is not active is listed: `INVALID_SUBACCOUNT_ID`,
  `SUBACCOUNT_NOT_FOUND`, `SWAP_NOT_PERMITTED`, `SERVICE_UNAVAILABLE`.

## Migration

None: the RPC is new. `GetSwap`, like `ListSwaps`, now also reads the Swaps
of a sub-account that is not active.
