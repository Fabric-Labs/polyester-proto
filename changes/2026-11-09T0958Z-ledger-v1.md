## What and why

Transfer history and transfer streams now define these existing movements in
`ledger.v1.TransferCode`, so clients can label them instead of showing an unknown reason:

| Value | Name | Meaning |
| --- | --- | --- |
| 1066 | `TRADING_WITHDRAW_FEE_LEG` | Fee paid when a trading withdrawal completes. |
| 1067 | `QUICKSWAP_POLYESTER_FEE` | QuickSwap fee paid to Polyester. |
| 1068 | `QUICKSWAP_BROKER_FEE` | QuickSwap fee paid to a broker. |
| 1069 | `QUICKSWAP_AFFILIATE_FEE` | QuickSwap fee paid to an affiliate. |
| 1072 | `FEE_SWEEP` | Collected fees transferred to the fee treasury's trading account. |
| 1073 | `FEE_REFILL` | Fee treasury funds transferred to replenish fee funds. |
| 1074 | `SYSTEM_ADJUSTMENT` | Balance adjustment with a system account, including account seeding. |

A system adjustment can credit or debit the user's account. Read `isDebit` to
determine its direction. Its transfer code remains 1074. REST and JSON transfer
streams label it `system_adjustment`.

## How clients use it

List transfers, newest first, with ConnectRPC:

```http
POST /ledger.read.v1.LedgerReadService/ListTransfers
Content-Type: application/json

{"limit":8,"reversed":true}
```

Or use REST:

```http
GET /v1/transfers?limit=8&reversed=true
```

The default limit is 100, maximum 1000. Omit `reversed` or set it to false for
oldest first. Continue with the opaque `nextPageToken` as `pageToken`, keeping
the same account, filters and ordering; an empty token ends the list. Transfer
amounts represent asset quantities with 18 decimal places. ConnectRPC returns
`amountE18` as unsigned 128-bit high/low parts; REST returns decimal amounts.
ConnectRPC reason names use the uppercase enum names above; REST and JSON
transfer streams use their lowercase spelling.

## Migration

Update generated contract bindings to recognize the added values. No request,
identifier, numeric transfer code or balance calculation changes are required.
The enum additions are wire-compatible. The REST and JSON transfer-stream label
for code 1074 changes from `operator_restore` to `system_adjustment`, so clients
matching that previous string must update their filters, type mappings and
display logic. This label change is the reason this note is marked breaking.
