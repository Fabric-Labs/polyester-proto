## What and why

A bot and each of its runs now name the strategy they were deployed from,
so a bot page can link to the strategy and show which saved revision the
bot runs.

- `Bot.strategy_id` (17) and `Bot.revision` (18): the strategy the bot's
  current run was deployed from, and that strategy's revision whose version
  the bot runs. `revision` is the number `ListStrategyRevisions` shows.
- `BotVersion.strategy_id` (6) and `BotVersion.revision` (7): the same for
  each run in `ListBotVersions`. A bot deployed again from another revision
  shows each run's own revision.
- Both are recorded when the deploy is proposed, so they are set for every
  bot, stopped bots included. Both read zero when the run has no linked
  strategy, for example once the strategy is deleted, as
  `DeployProposalSummary.strategy_id` and `revision` already do then.
- A version can be the content of several strategies' revisions, for
  example after a fork or a duplicate, so `version_id` alone never tells
  which strategy a bot came from: read these fields.

## How clients use it

`GetBot`, `ListBots` and `ListBotVersions` return the new fields; no request
changes.

```json
// POST /strategies.v1.StrategiesService/GetBot
{"botId": "9071245063421866091"}
// -> {"bot": {"botId": "9071245063421866091", "name": "Weekly DCA",
//      "status": "STOPPED", "versionId": "v_...",
//      "strategyId": "5905316723483801479", "revision": "2", ...}, ...}

// POST /strategies.v1.StrategiesService/ListBotVersions
{"botId": "9071245063421866091"}
// -> {"versions": [
//      {"versionId": "v_...", "strategyId": "5905316723483801479", "revision": "2", ...},
//      {"versionId": "v_...", "strategyId": "5905316723483801479", "revision": "1", ...}]}
```

Open the strategy with `GetStrategy(strategy_id)` and the revision with
`ListStrategyRevisions(strategy_id)`. When `strategy_id` is zero, the run
has no linked strategy, for example because the strategy was deleted: show
the run's version and dates instead.

## Migration

None: the fields are new, and both read zero for a run with no linked
strategy, for example once the strategy is deleted.
