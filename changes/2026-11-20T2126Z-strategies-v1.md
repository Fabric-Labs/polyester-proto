## What and why

`GetStrategyReference` now returns the whole runtime catalog. Until now it
left `indicator_library`, `manifest_schema`, `indicators` and `limits`
empty. Every field of `GetStrategyReferenceResponse` is now always set:

- `indicator_library`: TA-Lib and the exact version every bot of the runtime
  version computes its indicators with.
- `manifest_schema`: a JSON Schema (draft 2020-12) of the manifest, with
  its fields, their types and their bounds. The validation
  `SaveDraftVersion` runs stays the authority, and also checks the rules
  that span fields.
- `indicators`: every indicator bot code may read, with each parameter's
  minimum, maximum, default and whether it is a whole number, its outputs in
  the order bot code reads them, and its warm-up in closed candles.
- `limits`: CPU and memory per handler call, state, code and manifest size,
  and `RunScenarios` calls per minute.

The runtime version is now `2026-12`. `2026-11` is no longer offered:
`GetStrategyReference` and `SaveDraftVersion` answer
`RUNTIME_VERSION_UNSUPPORTED` for it, and versions saved under it are not
carried forward. Strategies has no shared deployment, so nothing running
depends on it.

`SaveDraftVersion`'s validation now refuses exactly the manifests the
schema refuses for one field's value, so a few manifests it accepted are
now refused:

- `limits: null` is refused, as leaving `limits` out already was.
- A decimal string has at most 28 digits. A price has at most 9 whole
  digits and 9 decimals. A quantity has at most 10 whole digits and 8
  decimals, and so does a candle's volume in a scenario.
- A `price_cross` key is 1 to 64 printable ASCII characters.
- A schedule's numbers are plain digits, with no sign, and its weekly time
  is written `HH:MM`.
- An order reference `#n` has at most 9 digits.
- The manifest schema states that a whole number (an update ID, a bot
  state number, `fast_interval_ms`) is at most 9007199254740991 in size,
  as `SaveDraftVersion` already refuses a larger one.
- `SaveDraftVersion` refuses, with `INVALID_ARGUMENT` naming its path, a
  manifest number a JSON double would change, such as
  `100.0000000000000001` (it would be read as 100) or `9007199254740990.5`.
  The same rule holds for every number inside a `google.protobuf.Struct` of
  a public request, the passkey credentials included.
- A scenario's `at` is from 1970-01-01T00:00:00Z to
  2554-07-21T23:34:33Z, and its observed candles open no earlier than
  1970-01-01T00:00:00Z.

Setting names and descriptions are now limited by characters, not bytes,
as `SettingValue` states them. A name of 64 accented letters is now
accepted.

`StrategyLimits.unique_indicator_settings` and
`StrategyLimits.backtests_per_day` are removed. Neither limit is enforced
yet, and a limit is listed only once it is. Each returns when the service
enforces it.

## How clients use it

The call needs no credentials:

```text
POST /strategies.v1.StrategiesService/GetStrategyReference
{}
```

Part of the response:

```json
{
  "runtimeVersion": "2026-12",
  "indicatorLibrary": {"name": "TA-Lib", "version": "0.8.3"},
  "indicators": [
    {
      "name": "rsi",
      "parameters": [{"name": "period", "minimum": "2", "maximum": "500", "integer": true}],
      "outputs": ["value"],
      "warmupBars": "period + 1"
    }
  ],
  "limits": {"cpuMsPerCall": 50, "memoryBytesPerCall": "33554432", "stateBytes": "65536", "codeBytes": "65536", "manifestBytes": "65536", "scenarioRunsPerMinute": 10}
}
```

`warmupBars` adds up parameter names and whole numbers with `+` and `-`.
Evaluated with the parameters a bot passes, it gives the closed candles that
must exist before the indicator has a value.

## Migration

Stop reading `limits.uniqueIndicatorSettings` and `limits.backtestsPerDay`:
the fields no longer exist. They were never set, so no value is lost.
Clients that treated an empty `manifestSchema` as "catalog not available"
now always receive the catalog.
Clients that pin `runtime_version` to `2026-11` send `2026-12`, or leave
it empty for the current version.
A manifest that relied on one of the newly refused forms above gets
validation errors from `SaveDraftVersion` naming the field. Write it in
the form the schema states.
