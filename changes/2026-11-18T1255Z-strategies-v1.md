## What and why

`GetStrategyReference` now also returns the skill pack: the guidance for
writing bots against the bot API reference (the workflow, the language
subset, patterns and pitfalls). A user's own AI assistant loads it next to
the reference to write better bots.

- `GetStrategyReferenceResponse.skill_pack`: the pack's documents, workflow
  first, each a new `SkillDocument` with its file `name` and `markdown`.
  Documents link to each other by those names.
- `GetStrategyReferenceResponse.skill_pack_version`: `sha256:` and a hash of
  the documents, so a client can tell when the pack changed and cache it
  until then.

The response's runtime catalog (`runtime_version`, `indicator_library`,
`manifest_schema`, `indicators` and `limits`) is not available yet and stays
empty until it is; the reference lists the indicators meanwhile. A request
naming a runtime version is refused with `RUNTIME_VERSION_UNSUPPORTED` until
then.

## How clients use it

`GetStrategyReference` is public and needs no credentials.

```json
POST /strategies.v1.StrategiesService/GetStrategyReference
{}

{
  "reference": "# Bot API reference\n…",
  "skillPack": [
    {"name": "writing-bots.md", "markdown": "# Writing a bot: the workflow\n…"},
    {"name": "language-for-bots.md", "markdown": "…"},
    {"name": "patterns.md", "markdown": "…"},
    {"name": "pitfalls.md", "markdown": "…"}
  ],
  "skillPackVersion": "sha256:…"
}
```

`skill_pack_version` is the lowercase hex SHA-256 of, for each document in
`skill_pack` order, the UTF-8 bytes of its name and then of its Markdown,
each preceded by its length in bytes as an unsigned 64-bit big-endian
integer. A client can recompute it to check what it cached.

## Migration

None: the fields are new, and clients that ignore them keep working.
