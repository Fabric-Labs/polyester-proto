## What and why

Two documented trigger request examples are corrected. No message, field,
enum value or RPC changes.

- **Modify Trigger.** The example set every patch field, including
  `limitPrice` (`limit_price_ticks`), which is not modifiable: a request
  that sets it is rejected with `TRIGGER_CHILD_PRICE_NOT_MODIFIABLE`, so the
  documented request could never succeed. It also mixed stop-loss and
  take-profit fields with trailing-stop-only fields. The example now sets
  the price protection of a stop-loss's market child to a 50 basis point
  (0.5%) cap, which tightens it only when the previous cap was wider, and
  answers the trigger's `ARMED` status.
- **Pause Trigger.** The REST example omitted `subaccountId`. A caller
  signed in with a session token that follows it addresses its root
  account, so pausing a subaccount's trigger answered `404
  TRIGGER_NOT_FOUND`. The example now names the subaccount, as the other
  trigger operations' examples do.

## How clients use it

Modify a subaccount's trigger by sending only the fields to change:

```http
PUT https://<api-host>/v1/triggers/59VD7Lar
Content-Type: application/json

{"triggerId":"59VD7Lar","subaccountId":"45LUmqjT","symbol":"BTC-USDT","maxSlippageBps":50}
```

```http
POST https://<api-host>/triggers.v1.TriggersService/ModifyTrigger
Content-Type: application/json

{"triggerId":"9155001234567","subaccountId":"6789012345678","symbolId":1,"maxSlippageBps":50}
```

Pause a subaccount's trigger with its subaccount:

```http
POST https://<api-host>/v1/triggers/59VD7Lar/pause
Content-Type: application/json

{"triggerId":"59VD7Lar","subaccountId":"45LUmqjT"}
```

A child limit price cannot be changed: cancel the trigger and create a new
one with the new limit price.

These examples act on a subaccount. Who sends `subaccountId` depends on the
credential:

- A session token names the subaccount; without it, the request acts on the
  root account.
- An API key bound to a subaccount acts on that subaccount; it may leave
  `subaccountId` out or name the same subaccount. Another subaccount is
  rejected with `API_KEY_SUBACCOUNT_MISMATCH`.
- A root-scoped API key acts on the root account only and must leave
  `subaccountId` out; naming a subaccount is rejected with
  `API_KEY_ROOT_SCOPE_ONLY`.

## Migration

None: the API is unchanged. A client that copied the previous Modify
Trigger example must stop sending `limitPrice`; a session-token client that
copied the previous Pause Trigger example must send the subaccount's
`subaccountId`.
