## What and why

**Availability:** devnet only. Not available on testnet yet; the service isn't deployed or routed there.

The assistant now uses only the memories that matter for a message, and keeps
a small profile of how the user wants to be addressed that applies to every
answer.

- New enum value `MemoryKind.PROFILE = 3`: a standing preference for how the
  assistant addresses and talks to the user, such as the name to use, the
  language, the tone and length of answers, or how risks are explained. A user
  holds at most 10 profile memories. ListMemories returns them with this kind.
- `MemoriesRecalled` now lists only the memories relevant to what was searched
  for. A message unrelated to every saved memory, such as "What are my
  balances?" or "hi", recalls none, so its event has an empty `memories` list.
  Before, a search returned up to 8 memories whatever their relevance.
- Profile memories are never searched and never appear in a
  `MemoriesRecalled` event: the assistant applies every one of them to every
  answer.

## How clients use it

ListMemories, as before; each memory carries its kind:

```text
POST /ai.v1.AssistantService/ListMemories
{"limit": 50}

{"memories": [
  {"memoryId": "4611686018427388003", "text": "Wants to be called Kestrel.", "createdAt": "2026-11-09T12:00:00Z", "kind": "PROFILE"},
  {"memoryId": "4611686018427388002", "text": "Their trading account is 12,000 USDT.", "createdAt": "2026-11-08T09:00:00Z", "kind": "PLANNING_FIGURE"},
  {"memoryId": "4611686018427388001", "text": "Their favourite market is SOL-USDT.", "createdAt": "2026-11-07T09:00:00Z", "kind": "FACT"}
]}
```

- Label a `PROFILE` memory as always used, for example "Always used". It
  applies to every answer whether or not a message mentions it.
- "Used N memories" under a reply counts the distinct `memory_id` values
  across the run's `MemoriesRecalled` events, as before. Profile memories are
  not among them, so do not add them to that count; show nothing when every
  event is empty.
- DeleteMemory deletes a profile memory like any other.

## Migration

None. Clients built on the previous contract keep working. A `MemoriesRecalled`
event may now be empty for a message that has nothing to do with the user's
memories, which the contract already allowed. A client that does not know
`PROFILE` yet sees an unknown enum value (3) on ListMemories; it should show
that memory as a plain memory until it labels profile memories.
