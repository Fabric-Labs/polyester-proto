## What and why

Statement export REST errors now answer the uppercase codes of the
`ledger.read.v1` error catalog, as the other ledger REST routes do. They
answered lowercase names, for example `idempotency_key_reused`. The
statuses, titles and details are unchanged; the `type` follows the code.

| Error | Before | Now |
| --- | --- | --- |
| An idempotency key reused with other fields | `409` `idempotency_key_reused` | `409` `IDEMPOTENCY_KEY_REUSED`; `type` unchanged |
| Too many exports queued or being produced | `429` `statement_export_limit_reached` | `429` `STATEMENT_EXPORT_LIMIT_REACHED`; `type` unchanged |
| An export whose file is not ready, has expired or failed | `409` `statement_export_not_ready`, `410` `statement_export_expired`, `409` `statement_export_failed` | `STATEMENT_EXPORT_NOT_READY`, `STATEMENT_EXPORT_EXPIRED`, `STATEMENT_EXPORT_FAILED`; `type` unchanged |
| An invalid page token, period or asset | `400` `bad_request` | `400` `BAD_REQUEST`; `type` unchanged |
| An invalid subaccount ID refused when the account is authorized | `400` `invalid_subaccount_id` | `400` `INVALID_SUBACCOUNT_ID`; `type` unchanged |
| An unknown export or subaccount | `404` `not_found` | `404` `NOT_FOUND`; `type` unchanged |
| A missing permission | `403` `permission_denied` | `403` `PERMISSION_DENIED`; `type` unchanged |
| No valid credentials | `401` `unauthenticated` | `401` `UNAUTHENTICATED`; `type` unchanged |
| Statement exports temporarily unavailable | `503` `upstream_error` | `503` `UPSTREAM_ERROR`; `type` unchanged |
| A malformed request, such as a body that is not JSON or an invalid query parameter | `400` `invalid_request`, `type` `.../invalid-request` | `400` `BAD_REQUEST`, `type` `.../bad-request` |
| A request that exceeded its deadline | `503` `deadline_exceeded`, `type` `.../deadline-exceeded` | `503` `UPSTREAM_ERROR`, `type` `.../upstream-error` |
| A temporary failure without a more specific code | `503` `unavailable`, `type` `.../unavailable` | `503` `UPSTREAM_ERROR`, `type` `.../upstream-error` |
| An unexpected server error | `500` `internal_error` or `internal`, `type` `.../internal-error` or `.../internal` | `500` `SERVER_ERROR`, `type` `.../server-error` |
| A canceled request | `499` `canceled`, `type` `.../canceled` | `499` `SERVER_ERROR`, `type` `.../server-error` |
| A file range outside the file | `416` `range_not_satisfiable` | `416` `RANGE_NOT_SATISFIABLE`; `type` unchanged |

## How clients use it

Branch on the uppercase `code`:

```text
POST /v1/statements/exports

409 application/problem+json
{"type":"https://polyester.dev/problems/idempotency-key-reused","title":"Conflict",
 "status":409,"detail":"idempotency_key_reused: The idempotency key was used for a statement export with other fields.",
 "code":"IDEMPOTENCY_KEY_REUSED"}
```

ConnectRPC is unchanged.

## Migration

A client that matched a lowercase `code` on `/v1/statements/exports` must
match its uppercase form instead, for example `IDEMPOTENCY_KEY_REUSED` for
`idempotency_key_reused`, and `BAD_REQUEST`, `UPSTREAM_ERROR` or
`SERVER_ERROR` where the table lists a new name. A client that matched a
changed `type` must match the new one.
