## What and why

Correct reference descriptions that could lead clients to interpret existing
responses or request defaults incorrectly. Message shapes, identifiers, enum
values, validation, and server behavior are unchanged.

Order versions cover execution state; asynchronously recorded fee totals and
requested enrichments may differ at the same version. CreateOrder acknowledges
admission without an execution status, and its required execution variant
selects time-in-force. Cancel-all counts submitted cancellation requests, whose
orders may execute before cancellation takes effect. Trigger configuration
includes successful modifications.

Omitted subaccount selectors use the bound subaccount for subaccount-scoped API
keys and the authenticated root for other callers. Asset quantity scales do not
change the fixed 18-decimal scale of account balance amounts. Quote-sized buys
must fit their entire all-in maximum quote debit within the applicable notional
maxima.

Columnar candle pages are ascending internally, but continuation moves toward
older candles. The current open candle appears last. Transfer history has no
hold-state filter. Self-trade prevention covers a root and all its subaccounts.
SBE cumulative order quantity includes predecessor executions, SETTLED does not
promise immediate trade-history visibility, and absent slippage overrides still
use default market protection. Funds-movement error descriptions use product-facing account language.

## How clients use it

With a subaccount-scoped API key, omit subaccountId to read that key's account.
For ConnectRPC JSON, send POST /ledger.read.v1.LedgerReadService/GetBalances:

```json
{}
```

The equivalent REST request is GET /v1/balances with the same authentication.
ConnectRPC balance amounts use fixed 18-decimal integer units. REST renders
those amounts as decimal strings.

For POST /marketdata.v1.MarketDataService/GetCandlesColumns, a minimal request is:

```json
{"symbolId": 1, "timeframe": "MIN_1", "limit": 100, "includeIncomplete": true}
```

Use a listed symbolId. Each page has increasing timestamps; pass nextPageToken
back as pageToken with the same symbol, timeframe, and time bounds to retrieve
older candles. Do not concatenate continuation pages as if each were newer.

## Migration

No API migration is required: wire formats and runtime behavior are unchanged.
Clients that implemented earlier descriptions should reconcile execution state
by order version while refreshing fee totals independently, inspect final order
states after cancel-all, and allow trade history to appear after SETTLED. Check
account selection, numeric scales, candle page ordering, and full quote budgets
against the corrected descriptions.
