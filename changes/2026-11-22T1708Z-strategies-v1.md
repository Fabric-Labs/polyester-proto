## What and why

`StrategyTemplate` gains `money_card` (field 7): what the template's bot may
do with money, the markets it trades and the events it handles. It is the same
card a version saved from the template unchanged shows, so a template page can
show where and when the bot runs, and its limits, before the user starts from
it. Before, a template carried only its manifest and code, and its "Runs on"
read empty.

## How clients use it

```http
POST /strategies.v1.StrategiesService/ListStrategyTemplates
{}
```

Each template now carries its card, for example:

```json
{"templateId": "weekly-dca", "moneyCard": {
  "maxOrder": {"asset": "USDT", "amount": "60"},
  "maxOpenGtcOrders": 2,
  "dailyLossThreshold": {"asset": "USDT", "amount": "100"},
  "markets": ["BTC/USDT"],
  "events": ["schedule mon 09:00 UTC"]}}
```

`budget` stays unset, as on a version's card.

## Migration

None: the field is new and optional to read.
