## What and why

`ListAssetInfo` now also returns market datapoints per asset: circulating, total and maximum supply, market capitalization, fully diluted market capitalization and market capitalization rank. Each value carries its source (CoinMarketCap, or the Polyester team) and the time the source observed or set it, so the asset Info tab can show live figures with their provenance and age.

## How clients use it

The request is unchanged:

```http
POST /marketdata.v1.MarketDataService/ListAssetInfo
Content-Type: application/json

{"assetIds":[1,2]}
```

```http
GET /v1/assets/info?assetIds=1&assetIds=2
```

Each `assetInfo` entry gains an optional `marketStats` object:

```json
{"assetId":1,
 "editorial":{"description":"…"},
 "editorialUpdatedAt":"2026-11-12T12:00:00Z",
 "marketStats":{
   "circulatingSupply":{"value":"20113162","source":"COINMARKETCAP","asOf":"2026-11-17T04:27:33.022Z"},
   "totalSupply":{"value":"20113162","source":"COINMARKETCAP","asOf":"2026-11-17T04:27:33.022Z"},
   "maxSupply":{"value":"21000000","source":"COINMARKETCAP","asOf":"2026-11-17T04:27:33.022Z"},
   "marketCapUsd":{"value":"1307009616822.71","source":"COINMARKETCAP","asOf":"2026-11-17T04:26:04Z"},
   "fullyDilutedMarketCapUsd":{"value":"1364638834673.38","source":"COINMARKETCAP","asOf":"2026-11-17T04:26:04Z"},
   "rank":{"value":"1","source":"COINMARKETCAP","asOf":"2026-11-17T04:27:33.022Z"}}}
```

- Every value is a nonnegative decimal string without sign or exponent, at most 64 characters. Supplies are in asset units, capitalizations in US dollars, and `rank` is a positive integer where 1 is the largest.
- `source` is `COINMARKETCAP` or `POLYESTER` (set by the Polyester team). Show "Source: CoinMarketCap" next to values from CoinMarketCap.
- `asOf` is the source's observation time (UTC RFC3339). Values are not removed when they age, so show the time with the value.
- An absent value is unknown; hide its row.
- `maxSupplyUnlimited` is present only when the source reports no maximum supply, for example `{"source":"COINMARKETCAP","asOf":"2026-11-17T04:27:33.239Z"}`; `maxSupply` is then absent. Show it as an unlimited maximum with its source and time. When both are absent the maximum is unknown.
- `marketStats` is absent when an asset has no market datapoints.

The list now also includes assets that have market datapoints but no team-written information. Such an entry has an empty `editorial` object and no `editorialUpdatedAt`; hide the editorial rows as for any empty field.

## Migration

None: `marketStats` is a new optional field. Clients that assumed every listed asset has team-written information should treat an empty `editorial` object as unknown, which the existing rendering rules already require.
