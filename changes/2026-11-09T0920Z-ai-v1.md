## What and why

**Availability:** devnet only. Not available on testnet yet; the service isn't deployed or routed there.

The assistant now tells clients which memories it used for an answer, so an
app can show "Used 3 memories" under the reply and expand it to the memory
texts.

- New `RunEvent` case `memories_recalled` (field 15), message
  `MemoriesRecalled { string tool_call_id = 1; repeated RecalledMemory memories = 2; }`.
- New message `RecalledMemory { fixed64 memory_id = 1; string text = 2; MemoryKind kind = 3; }`.
- New enum `MemoryKind { KIND_UNSPECIFIED = 0; FACT = 1; PLANNING_FIGURE = 2; }`.
- New field `Memory.kind = 5`: ListMemories returns each memory's kind.

The assistant searches the user's memories for their message before it
answers, and may search again while answering; each search is a
`recall_memories` tool call. Every successful search is followed by one
`MemoriesRecalled` event, also when it found nothing (empty `memories`). A
failed search has only its `ToolFinished` event with `ok: false`, and no
`MemoriesRecalled` event. The event is recorded like every other run event,
so replaying the run with WatchRun from `after_seq` 0, or resuming it, returns
it unchanged.

## How clients use it

Watch a run as before; the new event arrives right after the search's
`ToolFinished` event:

```text
POST /ai.v1.AssistantService/WatchRun
{"runId": "6349022007070785130", "afterSeq": "0"}

{"event": {"seq": "1", "toolStarted": {"toolCallId": "memory-recall", "name": "recall_memories", "input": {"k": 8}}}}
{"event": {"seq": "2", "toolFinished": {"toolCallId": "memory-recall", "name": "recall_memories", "ok": true}}}
{"event": {"seq": "3", "memoriesRecalled": {"toolCallId": "memory-recall", "memories": [
  {"memoryId": "4611686018427388001", "text": "favourite market: SOL-USDT", "kind": "FACT"},
  {"memoryId": "4611686018427388002", "text": "account size: 12000 USDT", "kind": "PLANNING_FIGURE"}
]}}}
```

- A search returns at most 8 memories, most relevant first.
- `memory_id` is the ID ListMemories returns and DeleteMemory accepts.
- To show "Used N memories" for a reply, count the distinct `memory_id`
  values across the run's `MemoriesRecalled` events; show nothing when there
  are none or all are empty.
- Label a `PLANNING_FIGURE` as for planning only: it is a figure the user
  stated, never a balance.
- `POST /ai.v1.AssistantService/ListMemories` now returns `kind` on each
  memory.

## Migration

None: the event, messages and field are new. A client built on the previous
contract skips the unknown `RunEvent` case, as the contract already requires.
