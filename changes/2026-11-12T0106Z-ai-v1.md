## What and why

`SendMessageRequest` takes an optional `page`, a new `CurrentPage` message
naming the page of the client the user is on as they send the message. The
assistant is told it, so it can answer "which page am I on?" and point within
that page instead of sending the user back to the page they are already on.

**Availability:** devnet only.

`CurrentPage` has three fields:

- `destination_id` (optional): the client's destination id for the page, when
  the page is one of its destinations (`Destination.id`), for example
  `page-settings`. Lowercase letters, digits and hyphens, 1 to 64 characters.
- `route`: the page's route template, each variable path segment named by its
  parameter in brackets, for example `/account/settings/[section]`. It starts
  with `/` and has at most 200 characters, each a letter, a digit or one of
  `/ - _ . [ ]`.
- `title`: the page's title as the client shows it, 1 to 80 characters.

A client must never send the URL the user sees, its query string or fragment,
or any id, symbol or other value taken from the path. A request outside these
bounds is `INVALID_ARGUMENT` and records nothing.

The page is part of the request the idempotency key covers: the same key with
another page, or with a page after none, is `IDEMPOTENCY_CONFLICT`.

## How clients use it

Send the page with every message, captured once per send:

```json
POST /ai.v1.AssistantService/SendMessage
{
  "text": "I still can't find where to change the language.",
  "idempotencyKey": "send-1f3c9a",
  "conversationId": "1234567890123456789",
  "page": {
    "destinationId": "page-settings",
    "route": "/account/settings/[section]",
    "title": "Settings"
  }
}
```

Omit `destinationId` for a page that is none of the client's destinations.
Omit `page` for a client without pages: the assistant is then told nothing
about where the user is. A retry of the same send repeats the page of its first
attempt, even if the user has moved on since.

## Migration

None: the field is new and optional. A client that does not send it behaves as
before.
