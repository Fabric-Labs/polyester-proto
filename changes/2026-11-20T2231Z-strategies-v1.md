## What and why

A strategy now shows the bot running from it, so a list of strategies can
show each one's status without reading every bot.

- **New: `Strategy.bot` (9), a `StrategyBot`.** It is the newest bot
  deployed from one of the strategy's deploy proposals that hasn't stopped:
  its `bot_id` and its `status`, `RUNNING` or `STOPPING`, as `GetBot` reads
  it. It is unset when no such bot exists.
- Only a deploy proposal links a bot to a strategy. A bot deployed from
  another strategy's proposal is never this strategy's bot, even when it runs
  the same version.
- **Only a caller who may read the bot sees it,** as `GetBot` decides: a
  session, an API key with `READ_STRATEGIES`, or a connected app with the
  `account:read` scope. For any other caller, `bot` is unset on every
  response, so an API key with only `DRAFT_STRATEGIES` never sees a bot.
- `GetStrategy`, `ListStrategies`, `RenameStrategy` and `CreateStrategy`
  return it in their `Strategy`. A new strategy has no bot, but a
  `CreateStrategy` retried with the same idempotency key returns the strategy
  as it is now, bot included.
- **New message:** `StrategyBot`.

## How clients use it

```http
POST /strategies.v1.StrategiesService/ListStrategies
Content-Type: application/json
Connect-Protocol-Version: 1

{"limit": 20}
```

```json
{"strategies": [
  {"strategyId": "…", "name": "Weekly DCA", "revision": "4",
   "headVersionId": "sha256:…", "valid": true,
   "bot": {"botId": "…", "status": "RUNNING"}, …},
  {"strategyId": "…", "name": "Grid draft", "revision": "2",
   "headVersionId": "sha256:…", "valid": true, …}
]}
```

The second strategy has no bot running from it, so `bot` is absent. A page
that lists strategies shows the bot's status beside each one that has a bot,
and links it to the bot's page through `GetBot` with its `botId`. A bot that
stops leaves the strategy: the next read shows the newest bot of the strategy
that is still running or stopping, or none.

## Migration

None. The field is new, and clients that don't read it are unaffected.
